# 화면 AI 구축 표준 절차

경비 대시보드와 손익 통합분석 화면에 AI 카드를 붙이며 실제로 했던 일을, **다음 화면에서 그대로 따라 할 수 있게** 순서로 정리한 문서입니다.
설계 배경은 [ai-agent-platform.md](ai-agent-platform.md)에 있습니다.

## 0. 카드를 무엇으로 나눌지 먼저 정한다
- 화면에 카드가 여러 장이면 **에이전트도 카드 수만큼** 나눕니다. 하나가 여러 장을 만들면 카드마다 물어본 문장이 반복됩니다.
- 나누는 축은 **업무 갈래**입니다. 순위(1·2·3위)로 나누면 세 에이전트가 같은 후보를 보고 같은 결론을 냅니다.
- 축은 화면이 이미 갖고 있습니다. 카드 아이콘이 다르면 그게 갈래이고, 설계 문서의 예시 항목이 갈래를 보여 줍니다.
- 배지 문구(«1 · 긴급»)는 화면이 **자리 순서로 고정**합니다. 모델에게 순위를 매기게 하지 않습니다.

## 1. 자리 카탈로그 등록
카드 한 장 = 자리 한 줄: `[도메인, 화면 키, 자리 키, 자리 항목, 이름, 설명, 순서]`

## 2. 에이전트 만들기
시드 스크립트 하나로 에이전트·출력 형식·파라미터를 함께 넣습니다. **이름 기준으로 지우고 다시 넣어** 몇 번을 돌려도 같은 상태가 되게 하고, 되돌리기 옵션을 둡니다.

## 3. 출력 계약 — 두 축을 구분한다
| 축 | 위치 | 하는 일 |
|---|---|---|
| 필드 강제 | 출력 파라미터 트리 → LLM `responseSchema` | 필드 이름·타입을 어기지 못하게 |
| 표시 골격 | 출력 형식 템플릿 | 마크다운 본문 골격(관리 화면에서 사람이 고치는 곳) |

- 카드 한 장짜리 계약은 배열 없이 **루트에 필드를 나열**합니다(예: `title · metric · desc · about · footer`).
- 파라미터 키는 **에이전트 단위로 고유**해야 합니다. 카드 자리를 접두사로 넣습니다.
- 출력 배열의 자식이 하나뿐이면 모델이 스칼라로 축약하는 경우가 있어, 배열이 필요하면 자식을 둘 이상 둡니다.
- `responseSchema`는 도구 호출(tools)과 함께 쓸 수 없으므로 화면 카드 에이전트에는 도구를 달지 않습니다.

## 4. 저장 키에 자리를 넣는다
결과 저장소를 쓰는 화면이면 `scope = "<자리 키>:<자리 항목>"`을 저장 키에 넣습니다. 카드를 쪼개고 키를 안 바꾸면 카드끼리 저장본을 덮어씁니다.

## 5. 화면 배선
- 배너 한 줄은 화면이 카드 결과로 만듭니다. 배너용 에이전트를 따로 두면 카드와 다른 말을 합니다.
- 조회는 축 하나당 한 번만: 조직 후보를 한 번 읽어 카드 3장이 나눠 씁니다.

## 6. 검증 — 세 단을 다 밟는다
1. **구문** — 컨트롤러·시드·테스트 `node --check`, 뷰·프래그먼트 XML 파싱, CSS 중괄호 짝
2. **계약** — 배포 데이터로 실호출과 표본 실호출 두 번
3. **화면** — 실제로 띄워 보고 레이아웃 점검 스크립트로 **수치로** 잽니다(위반 0)

### 6-2. 미리 채워 두기 — 정기 배치
화면의 요청 본문 빌더를 **서버가 재현**해 월 마감 기준으로 전 조직 결과를 미리 만듭니다. 후보가 0건인 조직은 부르지 않습니다.

## 7. 실제로 밟은 함정
- **자리 카탈로그 동기화는 없는 자리만 넣는다** — 자리를 1칸에서 3칸으로 쪼개면 옛 칸이 선택지에 남습니다. 별도로 사용 안 함 처리해야 합니다.
- **중첩 `$expand` 안의 `;`** — 상위 `$filter`와 함께 오면 approuter가 공백을 `+`로 바꿔 CAP 파서가 400을 냅니다. 중첩 `$select`에서 `;`를 없앴습니다.
- **이중 인코딩** — `encodeURIComponent(값)`을 다시 `encodeURI(전체 URL)`로 감싸면 `%25EA…`가 됩니다. 한쪽만 씁니다.
- **모델 응답 형식** — 한 줄에 하나씩 쓰라고 해도 구분자로 이어 붙이는 경우가 있어, 화면이 문장 부호로도 나눕니다. 금액 표기는 «숫자와 천 단위 쉼표»를 예시와 함께 못 박습니다.
- **캐시** — 소스를 바꾼 뒤에는 캐시 무시 새로고침을 한 번 더 해야 브라우저가 옛 XML을 놓습니다.

## 8. 마무리 체크리스트
- [ ] 카드 수 = 자리 수 = 에이전트 수
- [ ] 파라미터 키 에이전트 단위 고유
- [ ] 저장 키에 자리 포함
- [ ] 구문 · 계약 · 화면 3단 검증 통과
- [ ] 정기 배치에서 후보 0건 조직 제외
