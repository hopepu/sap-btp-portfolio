# 새 칸 백필 스크립트 패턴

데이터 모델에 칸을 새로 추가했을 때, **이미 있는 수천 행**을 안전하게 채우는 일회성 스크립트의 기본 틀입니다.
손익 파이프라인에 "담당 조직" 칸을 추가하면서 기존 약 5,900행을 이 방식으로 채웠습니다.

## 배경
파이프라인 데이터에 조직이 없어 프로젝트를 거쳐 조직을 유추했는데, 프로젝트가 없는 계약 전 건은 어느 조직에도 보이지 않았습니다.
조직 칸을 추가하고 화면·집계가 이 칸을 우선 쓰게 바꾼 뒤, 기존 행은 원천 데이터에서 조직을 찾아 채웠습니다.

## 안전장치
| 원칙 | 이유 |
|---|---|
| 기본은 미리보기, `apply`를 줘야 반영 | 실수로 실행해도 아무 일도 일어나지 않게 |
| 칸 배포 여부 먼저 확인 | 배포 순서가 꼬여도 오류 대신 안내 |
| `IS NULL`인 행만 채움 | 사람이 넣은 값 보존, 여러 번 돌려도 같은 결과(멱등) |
| 채울 행 ID를 파일로 백업 | 되돌리기 = 그 ID들만 다시 NULL |
| 매핑 실패(원천 없음·조직명 불일치)를 따로 집계 | 조용히 빠지는 행이 없게 |
| 파라미터 바인딩 + 묶음 UPDATE | SQL 주입 방지, 긴 IN 절 제한 회피 |

## 실행 순서
1. 엔티티(새 칸) 배포
2. `node backfillColumn.js` — 건수·조직별 분포·매핑 실패 확인
3. `node backfillColumn.js apply` — 백업 파일 생성 후 반영
4. 화면·집계 수치를 배포본에서 다시 확인
