## 권한 시스템 재설계 (가장 큰 작업)
- 권한 구조를 깊게 파악한 뒤 **보안 우선순위(P0~P3)**로 정리하고 무인증 노출 구간부터 막았습니다.
- XSUAA 속성 기반 조직 범위 → 서버 강제 필터 → 버튼 권한 공용 유틸 순서로 구축했습니다.
- 흩어져 있던 권한 판정 모듈을 **한 벌(authz)**로 통합했습니다. → [samples/cap-authz](../samples/cap-authz)
- 조직 접근 권한에 **하위 부서 자동 포함**을 도입하고, 소속 기본 권한 + 추가 권한 = 최종 권한 구조로 정리했습니다.
- 개인정보(계좌·주소) 마스킹을 적용했습니다. → [samples/cap-pii-mask](../samples/cap-pii-mask)
- 테스트 계정 15개로 실제 로그인해 권한 시나리오 20건을 검증했습니다.
- 관리자 메뉴 19개 화면을 배포본에서 전수 점검했습니다.
